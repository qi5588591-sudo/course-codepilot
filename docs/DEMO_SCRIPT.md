# 工程讲解与操作演示讲稿

## 工程讲解视频

工程讲解视频可介绍架构、功能、测试和已知限制。仓库附带的讲解素材不冒充真实模型操作结果。

开场：本课程设计选择第 32 题，以 VS Code 插件为入口，用 Python 后端调用云端模型。
开发者可以描述需求生成代码，也可以选择已有函数进行解释、审查、测试生成、文档生成和错误修复。

架构：插件只收集当前代码和用户主动添加的文件。后端按任务构造提示词，解析结构化结果，并将任务结果保存到 SQLite。
Python 验证使用禁网的 Docker 容器。容器不可用时会返回未验证。

实现特色：第一项是上下文处理，结合光标附近代码和 Python 符号摘要。
第二项是测试反馈修复，固定测试，先执行验证，再把失败日志交给模型，最多修复两轮。

工程检查：后端自动测试使用模拟模型和模拟执行器验证编排逻辑，独立题目测试检查人工参考实现。
这些数字代表工程检查，不代表大模型准确率。正式模型实验需要配置 API 和 Docker 后运行评估脚本。

## 真实操作录屏顺序

1. 显示 /health 中的实际模型，打开 CodePilot。
2. 用自然语言生成二分查找函数，预览并保存结果。
3. 请求光标补全，演示命名建议与函数建议。
4. 打开 binary_search_bug.py，选中函数，运行审查。
5. 生成测试，核对边界断言，然后用独立 test_binary_search.py 验证缺陷代码。
6. 点击验证并修复，展示每轮真实日志和修复差异，确认测试未修改。
7. 生成 API 文档并保存 Markdown。
8. 简短展示 Java、JavaScript、C++ 生成结果。
9. 显示实验 CSV，解释首次通过率、修复后通过率、耗时与局限。
