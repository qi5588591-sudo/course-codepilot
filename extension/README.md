# CodePilot 智能编程助手

课程设计第 32 题，支持 Python、Java、JavaScript、C++。

1. 启动项目根目录的 Python 后端，默认地址 `http://127.0.0.1:8765`。
2. 在活动栏打开 CodePilot，输入需求或选中代码，然后选择开发任务。
3. 生成、解释、审查、测试、文档、错误修复、命名和函数建议均从侧栏进入。
4. 命令面板执行 `CodePilot: 请求代码补全` 获取光标处行内补全。自动补全默认关闭，可在设置中启用。
5. 代码修改支持查看差异和点击应用；原文件变化后必须重新生成。
6. Python 自动测试需要 Docker 与项目的 sandbox 镜像；测试固定从 `solution` 导入。

生成测试后可直接验证原代码。生成代码后，先打开为新文件并保存，再对函数生成测试。
可以将测试代码粘贴到旧生成结果的验证区，或在生成测试任务下直接验证原函数。

当前选区、光标上下文及主动添加的相关文件会发送到所配置的云模型。不自动读取整个工作区。
模型密钥仅在 Python 后端配置。可选的本地后端令牌通过命令 `CodePilot: 设置后端令牌` 写入 VS Code SecretStorage。

详细环境、评估与验收说明见工程根目录 README。
